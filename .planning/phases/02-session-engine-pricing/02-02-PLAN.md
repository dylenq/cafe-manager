## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-07 | Elevation of Privilege | /rate-rules and /settings pages | high | mitigate | [Authorize] attribute on both pages; anonymous redirect tests |
| T-02-08 | Tampering | rate rule Value, Priority, times | medium | mitigate | server-side validation (Value above 0, Multiplier cap 100, Priority 0 to 1000, days not None, start not equal end) independent of UI |
| T-02-09 | Tampering | warning minutes comma list parsing | medium | mitigate | strict invariant-culture int parse, range 1 to 60, normalisation; malformed stored data falls back to defaults |
| T-02-10 | Repudiation | rule or setting changes not audited | low | accept | session audit trail (SESS-10) covers session actions only; config audit is out of v1 scope |
| T-02-SC | Tampering | package installs | high | accept | no packages are installed in this plan |
</threat_model>
