<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LAN client to /hubs/agent | Any device on the cafe LAN can reach the hub; only a holder of the shared key may connect |
| Agent to server (headers) | X-Machine-Id is attacker-controllable text used for lookups and logging |
| Session mutation to agents | A failing agent send must not corrupt or fail a committed session mutation |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Spoofing | AgentAuthMiddleware | high | mitigate | Shared 256-bit random key checked on every request to the hub route; SHA256 + CryptographicOperations.FixedTimeEquals; identical 401 for missing and wrong key; throttling is unnecessary at 256-bit entropy |
| T-03-02 | Information disclosure | Agents:SharedKey in Setting table, logs | medium | mitigate | Key is never written to logs or responses; shown only on the authenticated /settings page (plan 03-02); regeneration disconnects agents |
| T-03-03 | Spoofing | Machine id claim by a key holder | low | accept | Anyone holding the key can claim any machine id; newest connection wins. Acceptable on a private cafe LAN with under 15 stations; documented in README by plan 03-05 |
| T-03-04 | Denial of service | Machine id header, connection flood | medium | mitigate | Machine id length and character validation; duplicate id replaces the old connection so the registry cannot grow beyond distinct ids |
| T-03-05 | Tampering | Session mutation vs agent push | medium | mitigate | Sinks run after commit inside per-sink try/catch with a 5 s send timeout; failures are logged and never roll back or fail the mutation |
| T-03-SC | Tampering | NuGet installs (SignalR.Client, Logging.Abstractions) | high | mitigate | Microsoft first-party packages only, pinned to 10.0.15; no research audit table exists (research disabled), so legitimacy is recorded as a human-check, not a blocking checkpoint: owner "Microsoft" on nuget.org for Microsoft.AspNetCore.SignalR.Client and Microsoft.Extensions.Logging.Abstractions |
</threat_model>
