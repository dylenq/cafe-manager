## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser to remote-control commands | Only a logged-in admin may power off or message PCs |
| Message text to agent screen | Staff-entered text displayed on a customer PC |
| Command audit table | Record of who/what/when for destructive commands |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-03-16 | Elevation of privilege | AgentRemoteControlService and PC menu | high | mitigate | Commands are reachable only from authenticated Blazor components ([Authorize] via _Imports); service validates station kind and agent id; no anonymous HTTP endpoint exists for commands |
| T-03-17 | Tampering | Accidental shutdown or free unlock | medium | mitigate | Confirmations for Unlock (free), Shutdown and Restart; buttons disabled while a command is in flight |
| T-03-18 | Repudiation | Manual commands | medium | mitigate | AgentCommandLog row for every attempt with time and outcome; no FK so the trail survives station deletion; shown on /sessions |
| T-03-19 | Injection | Message text and log display | medium | mitigate | Message trimmed to 500 chars with control characters stripped; Razor encodes log rows; the WPF toast renders plain text (plan 03-05) |
| T-03-20 | Denial of service | Command flood to an agent | low | accept | Staff-only UI with in-flight disabling; at fewer than 15 stations no rate limiter is needed |
| T-03-SC | Tampering | NuGet installs | high | accept | No packages installed in this plan |
</threat_model>
