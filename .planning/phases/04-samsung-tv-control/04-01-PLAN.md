## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server to TV (LAN) | TV presents a self-signed certificate; replies are untrusted device data |
| TV reply to server | JSON from the TV is parsed and its fields may be shown in messages |
| DB to logs | Station.TvToken is a credential for the TV remote channel |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Spoofing | SamsungTvTransport WebSocket certificate callback | medium | mitigate | Callback accepts any certificate only on the ClientWebSocket created for a configured station IP; grep gate proves it exists in no other file and no process-wide override exists; LAN-only risk accepted per locked decision D-02 |
| T-04-02 | Information disclosure | Station.TvToken and wss URL | high | mitigate | Token never logged, never returned from TvPairingService, URI never logged; grep gate on Log calls |
| T-04-04 | Denial of service | WoL UDP broadcast | low | mitigate | Fixed 3 rounds x 4 datagrams per action; MAC validated before building a packet; per-TV serialisation |
| T-04-05 | Tampering | Retried or concurrent KEY_POWER toggles | high | mitigate | State is checked before every key; per-TV semaphore; handler skips a station with a new non-ended session; unit tests cover each |
| T-04-14 | Denial of service | Malformed TV JSON or hostile reply | low | mitigate | Parse failures map to Unknown/Failed, never throw; receive timeouts bound every wait |
| T-04-SC | Tampering | npm/pip/cargo/NuGet installs | high | accept | No new packages in this plan (ClientWebSocket, HttpClient, UdpClient, Kestrel are in the shared framework); acceptance criterion checks csproj files unchanged |
