<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LAN -> Kestrel :5080 | any device on the LAN can reach the server once the firewall rule exists |
| installer (admin) -> filesystem/service manager | elevated script writes Program Files, ProgramData, services |
| log writers -> log file | message text can contain newlines from user input |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-06 | Information Disclosure | ProgramData\CafeManager (cafe.db, backups) | high | mitigate | install-server.ps1 strips inheritance and grants only SYSTEM and Administrators (SID based) |
| T-07-07 | Tampering | connection string / data dir override | medium | mitigate | Explicit ConnectionStrings:Cafe wins by documented precedence; Cafe:DataDirectory only read from server config, never from request input; tested |
| T-07-08 | Repudiation / Tampering | FileLoggerProvider | low | mitigate | Newlines inside a message are folded onto continuation lines so user input cannot forge a log record; logger never throws |
| T-07-09 | Elevation of Privilege | service account | medium | accept | Runs as LocalSystem for simplicity on a dedicated front-desk PC; documented in INSTALL.md; v2 may move to a virtual service account |
| T-07-10 | Information Disclosure | firewall scope | medium | mitigate | Rule limited to Private,Domain profiles; Public networks stay blocked and the installer warns |
| T-07-11 | Denial of Service | backup disk use | low | mitigate | Retention keeps only Backup:Keep newest files; temp file moved atomically so a failed run leaves no partial backup |
| T-07-SC | Tampering | npm/pip/cargo installs | high | accept | No new packages; Microsoft.Data.Sqlite already comes with EF Core Sqlite 10.x |
</threat_model>
